# Sistema de Loja Virtual

Projeto desenvolvido para a atividade de Gerência de Configuração da disciplina 2026.2 - Fundamentos de Engenharia de Software - Turma 01, com o objetivo de aplicar na prática os conceitos de controle de versão utilizando Git e GitHub.

## Objetivo do sistema

Desenvolver uma loja virtual simples em linguagem C, permitindo o cadastro e o gerenciamento básico de produtos.

## Principais funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Busca de produtos
- Controle de estoque
- Registro de compras

## Tecnologias utilizadas

- Linguagem C
- Git
- GitHub
